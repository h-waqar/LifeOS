## 1. Objective

Implement the forward database schema and migration defining the data layer foundations for agent identity, scoped capabilities, cryptographic human-in-the-loop (HITL) approval challenges, and immutable forensic audit logging:
1. **Schema Definitions (`src/server/db/schema/agents.ts`):**
   - `agent_tokens`: Store agent registration metadata, SHA-256 token hash (never plaintext tokens), token prefix, provider attribution, status (`active`, `revoked`, `expired`), expiration timestamp, and ownership reference to `user.id`.
   - `agent_permissions`: Granular permission grants associated with `agent_tokens.id` covering capabilities (`READ`, `WRITE`, `EXECUTE`, `DESTRUCTIVE`, `SENSITIVE`), resource scoping, and action scoping.
   - `agent_challenges`: Pending and resolved human-in-the-loop approval challenges holding cryptographically unpredictable challenge IDs, argument hashes, capability requirements, timestamps, and lifecycle status (`PENDING`, `APPROVED`, `REJECTED`, `EXPIRED`, `CONSUMED`).
   - `agent_audit_log`: Detailed forensic log capturing agent actions, provider/session metadata, tool name, capability tier, arguments (with secret redaction), argument hash, challenge linkage, duration, before/after states, diffs, and execution outcome.
2. **Schema Aggregator (`src/server/db/schema/index.ts`):**
   - Export all agent tables, relations, and TypeScript inferred types (`AgentToken`, `AgentPermission`, `AgentChallenge`, `AgentAuditLog`).
   - Define `PHASE_13_TABLE_NAMES = ["agent_tokens", "agent_permissions", "agent_challenges", "agent_audit_log"] as const`.
3. **Forward Migration (`src/server/db/migrations/0027_agent_safety_and_audit.sql`):**
   - Clean DDL creating the 4 tables with foreign keys (`ON DELETE CASCADE` / `ON DELETE SET NULL`), check constraints, unique constraints, and performance indexes.
   - Append journal entry `0027_agent_safety_and_audit` with `idx: 27` to `src/server/db/migrations/meta/_journal.json`.
   - Strictly preserve historical migrations `0000_...` through `0026_...`.
4. **Verification Test Suite (`scripts/tests/phase-13/plan-01/schema-migration.test.ts`):**
   - Verify table column definitions, constraints, indexes, and journal consistency.
