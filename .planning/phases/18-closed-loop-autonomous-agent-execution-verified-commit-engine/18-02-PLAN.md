# Plan 18-02: Verification Qualification Leases, Sandboxed Audited Commit & Pre-Commit Hook Gating

## Objective
Build upon the closed-loop execution engine delivered in Plan 18-01. Ensure that Git commits performed through supported LifeOS workflows require valid verification evidence and that ordinary Git commit attempts are subject to repository-level verification enforcement.

## Requirements & Scope

1. **Verification Qualification Leases (`VerificationLease`)**:
   - Typed lease binding verification results to canonical repository identity, authenticated user/session, and working-tree candidate state.
   - Robust candidate fingerprint capturing HEAD commit, staged index (`git ls-files --stage`), status porcelain (`git status --porcelain=v1 -uall`), unstaged diff (`git diff`), and untracked file contents (`git ls-files --others --exclude-standard`).
   - Lease invalidation: expiry (TTL), working tree drift, staged changes drift, untracked changes drift, cross-repo reuse, single-use atomic consumption, and replay rejection.

2. **Audited Sandboxed Git Commit Execution (`lifeos workspace commit` / `lifeos_workspace_commit`)**:
   - Gated under EXECUTE tier capability; denies unauthorized agents; prevents caller spoofing.
   - Requires valid Verification Qualification Lease matching exact current candidate state.
   - Strict staging policy: commits qualified staged candidate; rejects empty staged changes; avoids silent staging of unverified changes.
   - Executes Git commit via sandboxed child process with argument array (no shell interpolation), timeouts, output bounds, and git hook preservation (no `--no-verify`).
   - Reconciles uncertain outcomes / timeouts without blind retries or duplicate commits.
   - Records full forensic audit trail (`beforeState` / `afterState`) in `agent_audit_log`.

3. **Pre-Commit Hook Gating & Management**:
   - Installable, idempotent pre-commit hook script (`scripts/workspace-pre-commit.cjs`).
   - Composes with and preserves existing non-LifeOS hooks via backup/chaining (`pre-commit.pre-lifeos`).
   - Blocks manual terminal `git commit` attempts lacking a valid verification lease matching candidate state.
   - Provides clear, actionable remediation messages on rejection.
   - Documented limitations: local hooks are advisory/cooperative; LifeOS commit workflow is authoritative audited boundary.

4. **Surface Parity & Documentation**:
   - CLI: `lifeos workspace commit`, `lifeos workspace lease create|verify`, `lifeos workspace hook install|uninstall|status`.
   - MCP: `lifeos_workspace_commit`, `lifeos_workspace_acquire_lease`, `lifeos_workspace_hook_status`.
   - Permissions evaluator: register `workspace.commit`, `lifeos_workspace_commit` under EXECUTE tier.
   - Update `skills/lifeos/workspace-development/SKILL.md` with commit workflow and lease lifecycle.
