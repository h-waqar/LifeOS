# Plan 16-02: Plan-to-Task Materialization & Pre-Commit Verification Gate

## Executive Summary
Delivers the plan materialization engine and pre-commit verification gate for LifeOS, completing Phase 16:
- **WORK-03 (Plan-to-Task Materialization)**: Enables agents to transform structured development plans into persisted LifeOS tasks linked to an active project. Validates full plan schemas, rejects duplicate steps, self-dependencies, missing dependencies, and cycles via Kahn's algorithm. Guarantees deterministic topological ordering, idempotent execution (same plan + version returns existing task graph without duplicate rows), atomic transaction boundaries, and zero-trust safety boundary gating (`WRITE` tier) with comprehensive audit logging.
- **WORK-04 (Pre-Commit Verification Gate)**: Enforces that agent code changes pass TypeScript compilation, unit/integration testing, build, and linting before allowing git commit execution. Executes a deterministic verification sequence (`typecheck` -> `test` -> `build` -> `lint`) using the Plan 16-01 validated workspace command runner. Adheres to strict fail-closed semantics (any failure immediately halts execution, marks subsequent checks as skipped, and blocks commit). Integrates safe, read-only git status inspection (`git status --porcelain` with `shell: false`), denying arbitrary git arguments or hooks alteration. Evaluated under the zero-trust `EXECUTE` tier with forensic audit logging.

## Objectives & Delivered Components

1. **Workspace Types Extended (`src/server/agents/workspace/types.ts`)**:
   - `PlanStepInput` & `MaterializeDevelopmentPlanInput`: strongly typed contracts for plan structures with step descriptions, priorities, durations, dependencies, and tags.
   - `PlanMaterializationResult`, `PlanMaterializationTaskSummary`, & `PlanMaterializationDependencySummary`: structured execution reporting.
   - `PlanValidationError` & `PlanMaterializationError`: typed error hierarchy.
   - `PreCommitVerificationInput` & `PreCommitVerificationResult`: contracts for pre-commit verification gates.
   - `VerificationCheckSummary` & `GitStatusSummary`: check-level exit statuses, durations, bounded output, and git state.
   - `VerificationGateError`: typed error class for gate failures.

2. **Plan-to-Task Materialization Engine (`src/server/agents/workspace/plan-materializer.ts`)**:
   - Schema validation (`developmentPlanSchema`, `planStepSchema`) bounding lengths, priorities, and durations.
   - Graph validation: duplicate step detection, self-dependency rejection, missing dependency assertion.
   - Kahn's algorithm topological sorting with deterministic ordering and cycle detection.
   - Target project validation: verifies project ownership by authenticated user and asserts project is not archived.
   - Idempotency engine: verifies if plan + version has already materialized, returning the existing task graph without duplicate rows.
   - Atomic transaction materialization: writes tasks and dependencies atomically with tags (`plan:${planId}`, `plan-version:${version}`, `plan-step:${stepId}`).
   - `runSandboxedPlanMaterialization`: canonical authorized wrapper delegating through `executeAgentOperation` (`WRITE` tier).

3. **Pre-Commit Verification Gate (`src/server/agents/workspace/verification-gate.ts`)**:
   - Deterministic verification pipeline: `typecheck` -> `test` -> `build` -> `lint`.
   - Delegates directly to `executeWorkspaceCommand` (no duplicate subprocesses).
   - Strict fail-closed semantics: any failure halts execution, marks remaining checks as `skipped`, and sets `canCommit: false`.
   - Read-only git inspection (`inspectGitStatus`): safely detects working tree status and merge conflicts without commit authority escalation or hook manipulation.
   - `runSandboxedPreCommitVerification`: canonical authorized wrapper delegating through `executeAgentOperation` (`EXECUTE` tier).

4. **Permission & Security Integration (`src/server/agents/permissions/evaluator.ts`)**:
   - Registered `workspace.materialize_plan` / `workspace.materializePlan` / `materializeDevelopmentPlan` under `WRITE` tier on `workspace` domain.
   - Registered `workspace.verify` / `workspace.precommit_verify` / `runPreCommitVerification` under `EXECUTE` tier on `workspace` domain.
   - Preserves denial-by-default for unclassified operations and enforces financial isolation.

5. **Adversarial Verification Suites**:
   - `scripts/tests/phase-16/plan-02/plan-materializer.test.ts` (26 tests):
     - Plan schema validation, bounds checking, duplicate step IDs.
     - Self-dependencies, missing dependencies, 2-node cycles, 3-node cycles, disconnected cycles.
     - Deterministic topological ordering.
     - Nonexistent, foreign, and archived project rejections.
     - Multi-step persistence with task dependencies and tags.
     - Atomic rollback on failure.
     - Idempotency and version increments.
     - Zero-trust authorization, anti-spoofing, unknown operation rejection, financial shield, and audit logging.
   - `scripts/tests/phase-16/plan-02/verification-gate.test.ts` (22 tests):
     - Full sequential pipeline execution (`typecheck`, `test`, `build`, `lint`).
     - Halting on failures (`typecheck`, `test`, `build`, `lint`), marking skipped checks.
     - Process timeout and launch failure handling.
     - Empty sequence rejection, prohibited commands rejection (`rm`, `curl`, `sh`, `bash`).
     - Path containment violations (`../`, null bytes, encoded traversals).
     - Read-only git status and merge conflict blocking.
     - Zero-trust evaluation (`EXECUTE` tier), anti-spoofing, unknown op denial, financial shield, and audit logging.
     - Real repository typecheck verification.
