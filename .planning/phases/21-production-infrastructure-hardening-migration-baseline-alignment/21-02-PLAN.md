# Plan 21-02: Production Deployment Hardening, TLS Termination, Reverse Proxy Forwarding, HTTP/2 & CDN Cache Control

## Executive Summary
Hardens the production request path and implements a comprehensive TLS, reverse proxy, HTTP/2, and private CDN cache-control verification harness:
1. **Next.js & Reverse Proxy Hardening (`next.config.ts`, `src/middleware.ts`)**:
   - Enforces HSTS (`Strict-Transport-Security: max-age=31536000; includeSubDomains; preload`) in production.
   - Refines `Permissions-Policy` to `camera=(), microphone=(self), geolocation=()`, enabling LifeOS voice dictation while blocking untrusted origins.
   - Implements Next.js edge-compatible middleware in `src/middleware.ts` to:
     - Handle and sanitize reverse proxy headers (`X-Forwarded-Proto`, `X-Forwarded-Host`, `X-Forwarded-For`).
     - Reject spoofed or invalid host headers and protocol forwarding attacks.
     - Enforce `Cache-Control: private, no-cache, no-store, max-age=0, must-revalidate` and `CDN-Cache-Control: no-store` on all `/api/*` endpoints and dynamic stateful routes, guaranteeing that intermediate CDNs and shared reverse proxies never publicly cache sensitive personal OS responses.
     - Permit immutable public caching on `/_next/static/*` assets and appropriate revalidation on PWA assets (`/manifest.webmanifest`, `/sw.js`, icons).
2. **Session & Cookie Security under Upstream TLS Termination (`src/server/auth/index.ts`)**:
   - Validates that Better Auth session cookies maintain `Secure`, `SameSite=Lax`, and `HttpOnly` attributes when TLS terminates at the reverse proxy (`X-Forwarded-Proto: https`).
3. **Reproducible Local TLS & HTTP/2 Reverse Proxy Harness**:
   - Establishes an automated test harness using Node.js TLS & HTTP/2 with self-signed certificates and real client execution (`curl --http2` and Node `http2` client).
   - Validates real HTTP/2 multiplexing, TLS handshake, header forwarding, canonical redirect behavior, and CDN cache headers.
   - Explicitly separates reproducible local infrastructure verification from external cloud-provider limits.
4. **Planning & Milestone Traceability**:
   - Reconciles Milestone v2.1 requirements across `ROADMAP.md`, `REQUIREMENTS.md`, and `STATE.md`, confirming ready status for milestone completion.

## Objectives
1. **Proxy & TLS Header Semantics (PROD-01)**:
   - Verify proper propagation and handling of `X-Forwarded-Proto`, `X-Forwarded-Host`, `X-Forwarded-For`.
   - Prevent spoofed Host headers or protocol downgrade attacks.
   - Verify HTTPS redirect and canonical URL behavior.
2. **HTTP/2 Compatibility (PROD-01)**:
   - Verify HTTP/2 multiplexed request execution over TLS in the local proxy harness.
   - Verify backward compatibility with HTTP/1.1 clients.
3. **Private CDN & Cache-Control Directives (PROD-01)**:
   - Prove authenticated API responses (`/api/tasks`, `/api/health`, `/api/auth/*`, etc.) return `private, no-cache, no-store, max-age=0, must-revalidate`.
   - Prove static build assets maintain public immutable caching.
   - Prove PWA manifest and icons maintain appropriate cache headers.
4. **Automated Regression Suite (PROD-01)**:
   - Deterministic automated tests in `scripts/tests/phase-21/plan-02/production-infrastructure.test.ts`.

## Acceptance Criteria
- HSTS and refined Permissions-Policy headers configured in production.
- Middleware guards `/api/*` with private, uncacheable headers (`CDN-Cache-Control: no-store`).
- Reverse proxy headers (`X-Forwarded-*`) handled safely without host spoofing vulnerabilities.
- Local TLS + HTTP/2 proxy harness validates live HTTPS and HTTP/2 requests with curl and Node http2.
- All Phase 21 Plan 02 tests pass cleanly.
- Full repository test suite passes with zero regressions.
- Next.js production build and TypeScript typecheck pass with exit code 0.

## Risks & Edge Cases
- *Edge case*: Reverse proxy forwards non-standard host headers — middleware normalizes and rejects invalid/untrusted host patterns.
- *Edge case*: CDN ignores `Cache-Control` — mitigated by adding explicit `CDN-Cache-Control: no-store` and `Surrogate-Control: no-store`.
- *Environmental boundary*: External cloud CDN edge nodes (Cloudflare/Fastly) are not deployed locally — verified via HTTP response contracts and local proxy simulation.
