# Plan 15-02: Web Speech API Voice Dictation & NLP Quick Capture Integration

## Executive Summary
Integrates native browser Web Speech API voice dictation into the LifeOS Universal Quick Capture modal. Transcribes spoken thoughts directly into structured inbox items, provides responsive visual feedback during recording with accessible controls, handles all browser permission and lifecycle error states fail-safe, and delegates spoken input through the existing NLP parsing pipeline to automatically extract task titles, dates, priorities, and tags without manual typing.

## Objectives
1. **Native Web Speech Hook (`src/hooks/use-speech-recognition.ts`)**:
   - Feature detect standard `SpeechRecognition` and `webkitSpeechRecognition`.
   - SSR-safe: zero global access during server rendering.
   - Support interim and final transcript streaming.
   - Handle permission denial (`not-allowed`), `no-speech`, `audio-capture`, and abort events with clear user-facing messages.
   - Clean lifecycle management: stop cleanly, reset transcript, abort on unmount.
2. **Accessible Voice Dictation Button (`src/components/voice/voice-dictation-button.tsx`)**:
   - Distinct visual states: idle, active/listening (pulsing accent, `aria-pressed="true"`), and disabled/unsupported.
   - Accessible labels: `aria-label="Start voice dictation"` and `aria-label="Stop voice dictation"`.
   - Interactive toggle behavior with error feedback.
3. **Modal Integration & NLP Pipeline (`src/components/quick-capture-modal.tsx`)**:
   - Embed dictation button within quick capture modal input bar.
   - Feed dictated transcript directly into input state and client token preview.
   - Support conversational speech extraction (e.g. `buy groceries tomorrow at 5pm urgent`) extracting title, priority, due date, scheduled date, and tags.
   - Treat voice input as untrusted: enforce strict validation and sanitization through existing domain services.
   - Offline fallback: persist voice-dictated tasks to IndexedDB offline queue when disconnected.
