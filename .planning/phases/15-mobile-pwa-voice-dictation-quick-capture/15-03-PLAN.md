# Plan 15-03: Mobile Capture & PWA End-to-End Verification Suite

## Executive Summary
Provides end-to-end integration and lifecycle verification for the complete Phase 15 mobile capture journey: opening quick capture, dictating text via Web Speech API, extracting structured attributes via NLP parsing, simulating offline network disruption, persisting items in the local IndexedDB queue, restoring network connectivity, synchronizing to PostgreSQL endpoints with deduplication and concurrency guards, and validating mobile responsiveness and error-free execution. Reconciles repository planning state across ROADMAP, REQUIREMENTS, and state.json.

## Objectives
1. **Full 15-Step End-to-End Journey Verification**:
   - Step 1: Open quick capture modal.
   - Step 2: Dictate speech via Web Speech API.
   - Step 3: Receive interim and final speech transcript.
   - Step 4: Parse speech transcript into title, priority, due date, scheduled date, and tags.
   - Step 5: Extract structured task/note fields.
   - Step 6: Simulate offline network state (`navigator.onLine = false`).
   - Step 7: Capture item while offline.
   - Step 8: Persist item locally in IndexedDB offline queue with strict `userId` tenant isolation.
   - Step 9: Restore network connectivity (`navigator.onLine = true` and `online` event).
   - Step 10: Trigger automatic synchronization via sync engine.
   - Step 11: Verify API route dispatch and database entity creation.
   - Step 12: Verify no duplicate submission occurs under concurrent or repeated triggers.
   - Step 13: Verify mobile-responsive layout and touch targets.
   - Step 14: Verify zero unhandled promise rejections.
   - Step 15: Verify zero unexpected console errors.
2. **Planning & Roadmap State Reconciliation**:
   - Reconcile `.planning/ROADMAP.md`: update Phase 15 and its three plans to complete (`[x]`).
   - Reconcile `.planning/REQUIREMENTS.md`: mark MOB-01, MOB-02, MOB-03, and MOB-04 as Complete (`[x]`).
