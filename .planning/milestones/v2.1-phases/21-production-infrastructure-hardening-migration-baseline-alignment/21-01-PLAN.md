# Plan 21-01: Drizzle Kit Migration Snapshot Baseline Reconciliation & Historical Chain Alignment

## Executive Summary
Reconciles the historical Drizzle Kit snapshot gap for migrations `0012–0026` (and `0027`) to establish an unbroken, verified introspection baseline while preserving migration journal integrity and preventing schema drift:
1. Reconstructs and aligns snapshot files for migrations `0012` through `0027` in `src/server/db/migrations/meta/`, linking sequentially from `0011_snapshot.json` to the current 50-table schema.
2. Validates that `_journal.json` remains completely intact and undisturbed (entries 0–27).
3. Verifies that `drizzle-kit check` passes with zero errors or warnings.
4. Verifies that `drizzle-kit generate` detects zero drift ("No schema changes, nothing to migrate 😴").
5. Verifies that a clean, fresh PostgreSQL database deterministically executes all migrations `0000–0027` via `runMigrations()`, reaching exact parity with the authoritative schema.
6. Implements automated regression tests in `scripts/tests/phase-21/plan-01/migration-baseline.test.ts` covering snapshot chain integrity, zero schema drift, journal consistency, and fresh database migration replay.

## Objectives
1. **Historical Snapshot Gap Reconciliation (PROD-03)**:
   - Generate valid Drizzle Kit v7 PostgreSQL schema snapshots for each migration from `0012` to `0027`.
   - Ensure the snapshot chain is continuous: `prevId` of snapshot $N$ strictly equals `id` of snapshot $N-1$.
   - Ensure `0027_snapshot.json` exactly matches the authoritative TypeScript definitions in `src/server/db/schema/index.ts`.
2. **Journal Non-Disruption & Tooling Alignment (PROD-03)**:
   - Maintain unchanged `src/server/db/migrations/meta/_journal.json`.
   - Ensure `pnpm exec drizzle-kit check` exits with code 0 ("Everything's fine 🐶🔥").
   - Ensure `pnpm exec drizzle-kit generate` exits with code 0 without generating spurious migration files.
3. **Fresh Database Deterministic Replay (PROD-03)**:
   - Validate that running all 28 migrations against a clean database succeeds without error.
   - Prove 100% parity across table count (50), column count (628), and index definitions between the replay database and the live database.
4. **Automated Migration Test Suite (PROD-03)**:
   - Automated tests in `scripts/tests/phase-21/plan-01/migration-baseline.test.ts` asserting all PROD-03 criteria.

## Acceptance Criteria
- All 16 snapshots (`0012` to `0027`) exist in `src/server/db/migrations/meta/` and validate under Drizzle Kit v7 schema.
- `drizzle-kit check` passes cleanly.
- `drizzle-kit generate` reports no pending migrations.
- Fresh database replay applies all 28 migrations with zero errors.
- Zero schema drift between TypeScript schema, snapshots, and PostgreSQL database.
- All tests in `scripts/tests/phase-21/plan-01/migration-baseline.test.ts` pass.

## Risks & Edge Cases
- *Edge case*: Snapshot parent ID mismatch causing collision in Drizzle Kit — mitigated by generating a strict linear UUID chain linking 0011 through 0027.
- *Edge case*: Checksum or timestamp differences in `_journal.json` — journal is strictly preserved read-only.
- *Risk*: Destructive schema change or column omission — verified by deep comparison of introspected DB schema vs serialized snapshot.
