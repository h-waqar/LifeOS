# Plan 11-02: MCP Personal Graph Resources & Standard Prompts

**Phase:** Phase 11: LifeOS Model Context Protocol (MCP) Server  
**Plan:** 11-02  
**Status:** Pending  
**Dependencies:** Plan 11-01 (MCP Server Foundation & Stdio Transport)  
**Requirements Covered:** MCP-02  

---

## 1. Objective

Expose the LifeOS personal context graph to agent harnesses via standard, readable MCP resources under `lifeos://context/*` (and canonical aliases) and provide standardized agent prompts:
1. **Context Overview Resource (MCP-02):** Implement `lifeos://context/overview` (and alias `lifeos://context/dashboard`):
   - Aggregates active goals, active projects, top daily tasks, upcoming calendar schedule, unread notifications, and today's habit completions.
   - Strictly reuses canonical application services without raw SQL: `getDashboardOverview` (`@/server/dashboard/service`), `listNotifications` / `getUnreadCount` (`@/server/notifications/service`), and `listTimeBlocks` (`@/server/calendar/service`).
2. **Entity Context Resources (MCP-02):** Expose focused context resources:
   - `lifeos://context/tasks/today` (and alias `lifeos://tasks/today`): Today's prioritized tasks with calculated priority scores, overdue tasks, and dependency blocking flags via `listTasks` (`@/server/tasks/service`).
   - `lifeos://context/goals/active` (and alias `lifeos://goals/active`): Active goals with progress rollups, horizons, and target metrics via `listGoals` (`@/server/goals/service`).
   - `lifeos://context/projects/active` (and alias `lifeos://projects/active`): Active projects with milestone counts, progress, and areas via `listProjects` (`@/server/projects/service`).
   - `lifeos://context/finance/summary` (and alias `lifeos://finance/summary`): Monthly financial health summary (net worth, cash flow, savings rate, category breakdown) via `getFinanceSummary` (`@/server/finance/reports-service`). Strictly READ-ONLY.
   - `lifeos://context/daily-plan` (and alias `lifeos://daily-plan/today`): Today's daily plan status, habit intentions, and morning/evening review state via `getDailyPlan` (`@/server/daily-plan/service`).
   - `lifeos://context/notifications` (and alias `lifeos://notifications/unread`): Unread notifications count and list via `listNotifications` (`@/server/notifications/service`).
3. **Deterministic Output & Payload Bounding:**
   - All resource representations return deterministic JSON with stable key ordering, null handling, and ISO 8601 timestamps.
   - Enforce bounded result sizes (e.g. max 50 tasks, max 20 notifications) to prevent enormous payloads from exhausting LLM context windows.
   - Secret scrubbing: ensure credentials, session cookies, and tokens are scrubbed from resource content before returning.
4. **Standard Agent Prompts (MCP-02):** Implement structured agent prompt templates:
   - `lifeos_morning_planning`: Guides agent in generating a prioritized daily plan by evaluating schedule blocks, active goals, overdue tasks, and habit intentions.
   - `lifeos_evening_review`: Guides agent in conducting an evening reflection, assessing completed vs pending tasks, and planning task rollover.
   - `lifeos_task_breakdown`: Guides agent in decomposing a high-level goal or project into sequenced, atomic tasks with estimated durations and dependencies.

## 4. Implementation Steps

1. **Context Overview Resource (`src/server/mcp/resources/context.ts`):**
   - Implement `handleContextOverview(context: McpContext)`:
     - Invoke `getDashboardOverview(userId, today)`.
     - Invoke `listNotifications(userId, { unreadOnly: true, limit: 10 })` and `getUnreadCount(userId)`.
     - Invoke `listTimeBlocks(userId, { startDate: todayStart, endDate: todayEnd })`.
     - Construct structured overview payload.
     - Return MCP Resource Read response:
       ```json
       {
         "contents": [
           {
             "uri": "lifeos://context/overview",
             "mimeType": "application/json",
             "text": "<deterministic JSON>"
           }
         ]
       }
       ```

2. **Entity Resources (`src/server/mcp/resources/entities.ts`):**
   - `lifeos://context/tasks/today` (and `lifeos://tasks/today`): Return today's tasks with priority scores, status, and overdue flags.
   - `lifeos://context/goals/active` (and `lifeos://goals/active`): Return active goals with progress rollups.
   - `lifeos://context/projects/active` (and `lifeos://projects/active`): Return active projects with milestones.
   - `lifeos://context/finance/summary` (and `lifeos://finance/summary`): Return current month financial report (net worth, cash flow, savings rate, category breakdown).
   - `lifeos://context/daily-plan` (and `lifeos://daily-plan/today`): Return today's daily plan and intentions.
   - `lifeos://context/notifications` (and `lifeos://notifications/unread`): Return unread notifications count and list.

3. **Resource Registry (`src/server/mcp/resources/registry.ts`):**
   - Register each resource on `McpServer` with name, URI, description, and MIME type `application/json`.
   - Ensure all resource outputs pass through `sortKeysDeterministically` and `scrubSecrets`.

4. **Standard Agent Prompts (`src/server/mcp/prompts/planning.ts` & `src/server/mcp/prompts/registry.ts`):**
   - Implement `lifeos_morning_planning`:
     - Arguments: `date` (optional string, defaults to today).
     - Fetches today's plan, schedule blocks, and top tasks.
     - Returns prompt messages instructing the agent to guide the user through their morning focus, calendar constraints, and habit commitments.
   - Implement `lifeos_evening_review`:
     - Arguments: `date` (optional string).
     - Fetches completed vs pending tasks, daily habits, and reflections.
     - Returns prompt messages instructing the agent to conduct a structured evening review and suggest task rollover.
   - Implement `lifeos_task_breakdown`:
     - Arguments: `goalId` or `projectId`, `title` (string).
     - Returns prompt messages instructing the agent to decompose the entity into 3–7 actionable, sequenced subtasks with estimated durations.

5. **Automated Verification (`scripts/tests/phase-11/plan-02/mcp-resources.test.ts`):**
   - Test resource listing returns all expected resource URIs and descriptions.
   - Test reading `lifeos://context/overview` returns valid deterministic JSON with user metrics, goals, tasks, and schedule.
   - Test reading `lifeos://context/tasks/today` returns prioritized tasks with blocking flags.
   - Test reading `lifeos://context/goals/active` and `lifeos://context/projects/active`.
   - Test reading `lifeos://context/finance/summary` returns monthly summary and contains zero mutation endpoints.
   - Test reading `lifeos://context/daily-plan` returns morning/evening state.
   - Test prompt listing and prompt generation for morning planning, evening review, and task breakdown.
   - Verify secrets are scrubbed and output ordering is deterministic.

## 6. Acceptance Criteria

1. MCP server registers and exposes `lifeos://context/overview`, `lifeos://context/tasks/today`, `lifeos://context/goals/active`, `lifeos://context/projects/active`, `lifeos://context/finance/summary`, and `lifeos://context/daily-plan`.
2. All resources return deterministic JSON with `application/json` MIME type and sorted keys.
3. Financial summary resource is strictly read-only and provides aggregated net worth and cash flow without exposing sensitive credentials or mutation paths.
4. Standard prompts (`lifeos_morning_planning`, `lifeos_evening_review`, `lifeos_task_breakdown`) generate structured messages grounded in live personal context.
5. All resource handlers delegate to canonical services and enforce authenticated user ownership.
