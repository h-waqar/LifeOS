# Plan 16-01: Project Workspace Isolation Sandbox & Validated Command Runner

## Executive Summary
Establishes the secure project-scoped execution sandbox and validated development command runner for LifeOS:
- Restricts all agent development execution to the canonical project repository root.
- Enforces strict path-relative containment semantics rejecting path traversals (`..`), null bytes (`\0`), URL-encoded and double-encoded traversals (`%2e%2e`), absolute external paths, and external symlink escapes.
- Employs fail-closed nearest-ancestor canonicalization for nonexistent paths to prevent symlink traversal attacks against newly created files.
- Provides a validated command runner restricted to a finite allowlist (`test`, `typecheck`, `build`, `lint`) executing with fixed binaries, explicit argument arrays, no raw shell string interpolation (`shell: false`), hard subprocess timeouts (60s/120s), graceful termination, and bounded output capture (1 MB limit with truncation notices).
- Fully integrates with the Phase 13 canonical zero-trust agent safety boundary (`executeAgentOperation`), verifying caller anti-spoofing, `EXECUTE` capability tier evaluation, denial-by-default for unclassified operations, financial shield enforcement, and forensic audit logging with secret redaction.

## Objectives & Delivered Components
1. **Workspace Types (`src/server/agents/workspace/types.ts`)**:
   - `ALLOWED_WORKSPACE_COMMANDS`: finite allowlist (`"test" | "typecheck" | "build" | "lint"`).
   - `RunWorkspaceCommandInput`: typed command input with optional subpath, validated args, and bounded timeout.
   - `WorkspaceCommandResult`: structured execution report (`exitCode`, `stdout`, `stderr`, `durationMs`, `passed`, `summary`, `timedOut`, `stdoutTruncated`, `stderrTruncated`).
   - `SandboxPathResolution`: structured containment verification contract.
   - Strongly typed error classes: `WorkspaceSecurityError` and `WorkspaceExecutionError`.

2. **Sandbox Containment Engine (`src/server/agents/workspace/sandbox.ts`)**:
   - `getCanonicalProjectRoot`: canonical realpath resolution of the repository project root.
   - `isPathContained`: path-relative containment semantics (`path.relative`) guarding against string prefix bypasses.
   - Pre-validation filtering: immediate rejection of null bytes, backslash sequences, and iterative percent-encoded traversals.
   - Existing path containment: full `fs.realpathSync` target validation inside sandbox root.
   - Nonexistent path resolution: recursive nearest-ancestor walking, canonicalization, and boundary assertion.
   - `assertSandboxPath`: fail-closed assertion returning verified canonical path or throwing `WorkspaceSecurityError`.

3. **Validated Command Runner (`src/server/agents/workspace/command-runner.ts`)**:
   - Command allowlist verification rejecting arbitrary commands or shell interpreters (`sh`, `bash`, `rm`, `curl`, etc.).
   - Argument validation: strictly restricts extra arguments, prohibiting flags starting with `-` (flag injection), shell metacharacters (`;`, `&`, `|`, `` ` ``, `$()`), traversal tokens, and sensitive file targets (`.env`, `.git/hooks`).
   - Process security: `child_process.spawn` with `shell: false`, sanitized environment stripping dangerous variables (`NODE_OPTIONS`, `LD_PRELOAD`, etc.), and process group leader assignment.
   - Hard timeouts: default 60s (120s for build), graceful `SIGTERM` followed by forced `SIGKILL`.
   - Bounded output streaming: 1 MB capacity for stdout and stderr with truncation flags and formatted notices.
   - `runSandboxedWorkspaceCommand`: canonical authorized wrapper delegating through `executeAgentOperation`.

4. **Permission & Security Integration (`src/server/agents/permissions/evaluator.ts`)**:
   - Registered canonical operations under `EXECUTE` tier: `workspace.run`, `workspace.test`, `workspace.typecheck`, `workspace.build`, `workspace.lint`, and `runWorkspaceCommand`.
   - Preserves denial-by-default for unclassified operations and enforces financial shield invariants.

5. **Adversarial Verification Suite (`scripts/tests/phase-16/plan-01/workspace-sandbox.test.ts`)**:
   - 39 automated adversarial tests covering:
     - Path containment (file, dir, nested, `../`, `../../`, embedded traversal, absolute external, null bytes, URL encoded, double encoded, prefix confusion).
     - Symlinks (internal accepted, external rejected, through external rejected, nonexistent valid descendant accepted, nonexistent through external rejected).
     - Command security (test, typecheck, build, lint accepted; unknown commands, shell commands, interpreters, and arbitrary executables rejected; argument injection, metacharacters, and cwd escapes rejected).
     - Process behavior (exitCode capture, stdout/stderr capture, timeout termination, hung process cleanup, stdout truncation, stderr truncation, launch failure handling).
     - Zero-trust authorization (canonical evaluator integration, permission denial when lacking `EXECUTE`, unclassified operation denial, financial shield preservation, audit logging attribution).
     - Real repository execution (`typecheck` verification under default production configuration).
