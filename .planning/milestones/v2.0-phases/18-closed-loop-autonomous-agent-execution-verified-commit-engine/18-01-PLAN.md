# Plan 18-01: Plan Execution Observability, Deterministic Next-Task Resolution & Closed-Loop Autonomous Execution

## Executive Summary
Completes the autonomous agent execution loop and plan observability foundation for Phase 18:
1. **Plan Execution Inspector & Deterministic Resolver (`src/server/agents/workspace/plan-inspector.ts`)**:
   - `getPlanExecutionStatus`: Comprehensive, machine-actionable state representation with progress percentage, step classifications (`COMPLETED`, `IN_PROGRESS`, `READY`, `BLOCKED`, `CANCELLED`), bottlenecks, and fail-closed cycle/error detection.
   - `getNextReadyPlanTask`: Resolves exactly one deterministic next ready task using deterministic tie-breakers (order index -> in-progress priority -> creation time -> lexicographical task ID), or returns explicit terminal states (`READY`, `COMPLETE`, `BLOCKED`, `INVALID`).
2. **Closed-Loop Step Execution & Reconciliation Engine (`src/server/agents/workspace/step-executor.ts`)**:
   - `executePlanStep`: Traces the full autonomous lifecycle: inspect plan status -> resolve next ready task -> transition to `in_progress` -> execute verification checks in sandboxed workspace -> verify actual outcomes -> persist status with bounded retries -> resolve next task.
   - Eliminates false progress: task completion is recorded ONLY after verification passes.
   - Eliminates infinite retry loops: enforces `maxRetries` (default: 3). Exceeding retries marks the task as `blocked` with explicit terminal failure status.
   - Distinguishes `EXECUTION_SUCCESS`, `VERIFICATION_FAILURE`, `RECOVERABLE_FAILURE`, `BLOCKED_DEPENDENCY`, `INVALID_PLAN`, `ALREADY_COMPLETED`, and `TERMINAL_FAILURE`.
3. **Agent Surface Parity (CLI, MCP Tools, Resources)**:
   - CLI commands (`lifeos workspace status`, `lifeos workspace next-task`, `lifeos workspace step`).
   - MCP tools (`lifeos_workspace_plan_status`, `lifeos_workspace_next_task`, `lifeos_workspace_execute_step`, `lifeos_list_tasks`, `lifeos_get_task`).
   - Observational resource (`lifeos://workspace/plans/{planId}`).
4. **Zero-Trust Safety & Capability Enforcement**:
   - READ tier for status and next-task inspection; EXECUTE tier for step execution.
   - Strict session binding and caller anti-spoofing assertion (`assertNoCallerSpoofing`).
   - Comprehensive audit logging (`beforeState` / `afterState`) in `agent_audit_log`.

## Verification Plan
1. `scripts/tests/phase-18/plan-01/mcp-task-queries.test.ts`: Verifies MCP task queries parity (`lifeos_list_tasks`, `lifeos_get_task`), filtering, session isolation, and capability enforcement.
2. `scripts/tests/phase-18/plan-01/plan-observability.test.ts`: Verifies plan execution status, topological ordering, cycle detection, deterministic tie-breaking, CLI subcommands, and anti-spoofing.
3. `scripts/tests/phase-18/plan-01/closed-loop-execution.test.ts`: Comprehensive integration test tracing sequential/branching DAG execution, partial materialization, verification failure halting, bounded retry exhaustion, terminal failure handling, interrupted execution recovery, stale status idempotency, real repository execution, and zero-trust audit attribution.
