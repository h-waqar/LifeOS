## 1. Objective

Implement and fully verify the remaining Phase 9 intelligence capabilities:
1. **Predictive Goal Risk Forecasting (INTEL-02):** A deterministic, explainable goal-risk forecasting engine that analyzes goal progress, target deadlines, historical completion velocity, task completion rates, overdue tasks, project progress, habit consistency, and time allocation. It produces structured forecasting projections (projected completion dates, velocity ratios, risk levels, confidence scores, contributing factors, and actionable recommendations) with robust handling of edge cases (missing deadlines, zero progress, overdue goals, and sparse data).
2. **PostgreSQL pgvector Semantic Knowledge Search (INTEL-03):** Conceptual semantic similarity search across LifeOS knowledge and content using PostgreSQL and the `pgvector` extension. Provides dedicated vector storage, embedding generation reusing existing AI infrastructure, user-level isolation, metadata filtering, threshold ranking, pagination, and graceful degradation when vector infrastructure is unavailable.

## 4. Implementation Steps

1. **Database Schema & Migration:**
   - Define `knowledge_embeddings` in `src/server/db/schema/embeddings.ts` with `vector("embedding", { dimensions: 768 })`.
   - Update `docker-compose.yml` to use `pgvector/pgvector:pg16`.
   - Create migration `0026_pgvector_knowledge_embeddings.sql` with `CREATE EXTENSION IF NOT EXISTS vector;` and HNSW cosine index.
   - Register migration 0026 in `src/server/db/migrations/meta/_journal.json`.
   - Update `src/server/db/schema/index.ts` with schema export and user relations.

2. **Goal Risk Forecasting Engine (INTEL-02):**
   - Create `src/server/goals/forecasting/types.ts`.
   - Implement `src/server/goals/forecasting/calculations.ts` with pure mathematical functions for:
     - Current velocity vs required velocity calculation
     - Overdue status and timeline gap evaluation
     - Data sufficiency detection and confidence scoring
     - Composite risk scoring (0-100) and risk level assignment (`on_track`, `low_risk`, `medium_risk`, `high_risk`, `critical`, `completed`)
     - Explainable contributing risk factors and actionable recommendations
     - Projected completion dates and optimistic/conservative completion windows
   - Implement `src/server/goals/forecasting/service.ts`:
     - `getGoalRiskForecast(userId, goalId)`
     - `getAllGoalsRiskForecasts(userId, options)`
     - Enforce strict user ownership validation.

3. **Embedding Infrastructure & Semantic Search Engine (INTEL-03):**
   - Implement `src/server/ai/embedding/provider.ts`:
     - Embedding generation using `@ai-sdk/google` (`text-embedding-004`) and `@ai-sdk/openai` (`text-embedding-3-small` with 768 dims).
     - Deterministic 768-dimensional fallback embedding generator for testing, offline environments, and provider failure.
   - Implement `src/server/search/indexing-service.ts`:
     - Index individual entities (notes, learning items, content items) into `knowledge_embeddings`.
     - Chunking, metadata preservation, and conflict resolution (`onConflictDoUpdate`).
   - Implement `src/server/search/semantic-service.ts`:
     - Query embedding generation, cosine distance calculation via pgvector, similarity threshold filtering, metadata filtering (by area, entityType), limit/offset pagination, and user ownership isolation.
     - Graceful degradation when pgvector or database is unavailable.

4. **API Endpoints:**
   - `GET /api/goals/[id]/forecast`
   - `GET /api/goals/forecast`
   - `GET /api/search/semantic` & `POST /api/search/semantic`
   - `POST /api/search/semantic/index`
   - `GET /api/search/semantic/status`
   - Protect all routes with `requireAuthenticatedUser`, Zod validation, error handling, and security cache headers.

5. **UI Integration:**
   - Build `GoalRiskBadge` and `GoalForecastDialog` components.
   - Integrate risk indicators into `src/app/goals/page.tsx`.
   - Enhance Goal Progress tab in `src/components/analytics/analytics-dashboard-view.tsx` with risk distribution.
   - Integrate semantic search mode into `src/components/command-palette.tsx`.

6. **Testing & Verification:**

   - Integration tests for goal forecasting service (user ownership, data rollups).
