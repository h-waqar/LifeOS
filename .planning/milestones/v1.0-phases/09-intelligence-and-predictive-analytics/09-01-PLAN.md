# Plan 09-01: Cross-domain Personal Analytics Dashboard and Trend Calculation Engine

**Phase:** Phase 9: Intelligence & Predictive Analytics  
**Plan:** 09-01  
**Status:** Complete  
**Dependencies:** Phase 1 Foundation, Phase 2 Core Productivity, Phase 3 Knowledge, Phase 4 Finance, Phase 7 Automations, Phase 8 Integrations  
**Requirements Covered:** INTEL-01, INTEL-04  

---

## 1. Objective

Deliver the cross-domain personal analytics foundation, deterministic trend calculation engine, schedule optimization recommender, and unified analytics dashboard for LifeOS.
1. **Cross-Domain Data Aggregation (INTEL-01):** Aggregate productivity and personal data across tasks, projects, goals, habits, calendar time blocks, daily plans, evening reviews, learning items, finance, and external GitHub activity.
2. **Deterministic Trend Calculation Engine (INTEL-01):** Compute historical trends, period-over-period percentage deltas, rolling averages, task completion velocity, habit consistency rates, estimation accuracy, overdue rates, and cross-domain correlations without opaque ML or hallucinating external calls.
3. **Schedule Optimization Recommendations (INTEL-04):** Suggest optimal focus blocks, peak productivity windows, and energy-level schedule allocations derived deterministically from historical task completions, energy tiers, timeblock execution, and evening review productivity scores.
4. **Analytics Snapshots & API Layer:** Provide fast, user-isolated query endpoints (`/api/analytics/dashboard`, `/api/analytics/recommendations`, `/api/analytics/snapshots`) and an `analytics_snapshots` relational schema for tracking and archiving historical analytics.
5. **Analytics Dashboard UI:** Create a responsive, keyboard-accessible analytics dashboard with date filters (7d, 30d, 90d, month), visual breakdown cards, trend badges, habit consistency tracking, velocity charts, goal progress rollups, and focus recommendations.
