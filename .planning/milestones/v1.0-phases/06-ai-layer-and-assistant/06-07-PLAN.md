## 4. Detailed Implementation Specification

### 4.1 Streaming Chat Handler (`src/app/api/ai/chat/route.ts`)
- Authenticates session using `requireAuthenticatedUser`.
- Resolves conversation or creates a new one.
- Ingests assembled context from `src/server/ai/context/engine.ts`.
- Invokes `streamText` with resolved model and registered tools from `src/server/ai/tools/registry.ts`.
- Automatically catches consequential tool calls and returns pending action tokens.
- On stream completion, persists assistant messages and updates token usage metrics in `ai_messages`.
- Enforces rate limiting (20 requests per minute per user).

### 4.2 Interactive Action Confirmation Card (`action-confirmation-card.tsx`)
- Renders directly in the chat stream when an action is in `'pending'` state:
  - Tool title and risk level badge (`Consequential` or `Destructive`).
  - Clear natural language description of what will happen.
  - Exact parameter diff (e.g. `Task: "Finish taxes"`, `Due: "Tomorrow"`, `Priority: "High"`).
  - 5-minute countdown timer before action expires.
  - "Approve" (green primary) and "Reject" (destructive/outline) buttons.
- On click, invokes `/api/ai/actions/[id]/confirm` or `/api/ai/actions/[id]/reject`.
- Transitions seamlessly to "Executed ✓" or "Cancelled ✕" upon response without page reload.

### 4.3 Global Slide-Over Drawer (`assistant-drawer.tsx`)
- Accessible from anywhere in LifeOS without losing current page state.
- Triggered by:
  - Header Sparkles button.
  - Keyboard shortcut `Cmd+J` / `Ctrl+J`.
  - Command Palette selection.
- Syncs seamlessly with the user's active conversation.

## 5. Testing Strategy

All tests strictly placed in `scripts/tests/phase-06/plan-07/`.

### Component Tests (`scripts/tests/phase-06/plan-07/assistant-ui.test.tsx`):
- Renders chat interface with conversation history and active model selector.
- Displays tool execution pills with appropriate icons and states.
- Action confirmation card displays parameter diff and triggers approval endpoint on click.
- Global slide-over drawer toggles visibility on `Cmd+J` keydown event.
- Citation badges render clickable links to target entities (`/notes?id=...`).

### Integration & End-to-End Tests (`scripts/tests/phase-06/plan-07/e2e-assistant.integration.test.ts`):
- Full conversation journey: User asks question → Assistant retrieves context from tasks/notes → Assistant responds with citations.
- Full mutation journey: User says "Create a task for tomorrow" → Model requests tool → Server intercepts and yields pending action → User approves action → Database commits task → Audit log is created → Conversation acknowledges completion.
- Rate limiting test: Spamming requests triggers 429 Too Many Requests.
- Mobile responsiveness: Chat and drawer adapt cleanly to viewport without layout shift.
