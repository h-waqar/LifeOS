## 4. Detailed Implementation Specification

### 4.1 Natural Language Quick Capture (`quick-capture-parser.ts`)
Uses `generateObject` with a strict Zod schema:
- Parses relative dates ("tomorrow at 3pm", "next Tuesday", "in two hours") relative to user's current timestamp and timezone.
- Extracts priority ("urgent", "low priority"), estimated duration ("takes about 45 minutes"), and tags.
- Identifies intent: creates task, schedules calendar block, or logs scratchpad note.
- Fails over gracefully to token-based parser (`parseQuickCaptureInput`) if AI provider is unreachable or disabled.

### 4.2 Proactive Daily Planning Suggestions (`daily-planner.ts`)
- Ingests:
  - Overdue tasks sorted by priority score.
  - Today's confirmed calendar blocks (calculating free focus hours).
  - Daily habits needing completion.
  - Active high-priority goals.
- Generates:
  - Recommended **Top 3 Focus Tasks** fitted to available working hours.
  - Realistic time-block schedule recommendation.
  - Warning flags for deadline bottlenecks.

### 4.3 Weekly Synthesis Review (`weekly-synthesizer.ts`)
- Ingests data from the previous 7 days:
  - Completed tasks count & project milestones achieved.
  - Habit consistency percentages (streaks, misses).
  - Financial movements (total expenses vs monthly budget pacing).
  - Published content items & logged metrics.
  - Learning progress updates.
- Generates a structured Markdown review:
  - **Velocity & Wins:** Core highlights and accomplishments.
  - **Friction & Drift:** Habits or goals falling behind.
  - **Financial Summary:** Spending pace assessment.
  - **Next Week Strategic Focus:** 3 proactive recommendations.

## 5. Testing Strategy

All tests strictly placed in `scripts/tests/phase-06/plan-06/`.

### Unit Tests (`scripts/tests/phase-06/plan-06/proactive-engine.test.ts`):
- NLP parser extracts title, priority, due date, duration, and tags from conversational text.
- Resolves relative temporal expressions correctly against provided reference date.
- Daily planner generates realistic top 3 focus tasks without exceeding available working hours.
- Weekly synthesizer aggregates 7-day metrics correctly and formats structured markdown sections.

### Integration Tests (`scripts/tests/phase-06/plan-06/nlp-planning.integration.test.ts`):
- Endpoint `/api/ai/parse-capture` accepts raw text and returns validated structured entities.
- Endpoint `/api/ai/daily-suggestions` queries live database for active user and returns tailored recommendations.
- Multi-tenant isolation: Suggestions for User A contain zero data or entity IDs from User B.

## 6. Acceptance Criteria

1. Natural language input parses complex text into valid structured tasks and calendar blocks.
2. Daily planning suggestions provide realistic focus items grounded in live task deadlines and free hours.
3. Weekly review synthesizes accomplishments, habits, finances, and goals across the past 7 days.
4. All tests in `scripts/tests/phase-06/plan-06/` pass with zero regressions.
