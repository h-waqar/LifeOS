## 1. Objective

Build the reliable, PostgreSQL-backed Background Job Scheduler and periodic domain sweepers. Deliver scheduled automation triggers for morning daily planning prompts (8:00 AM), evening review reminders (9:00 PM), overdue task detection, and 14-day stagnant goal alerts without external Redis or broker dependencies. Guarantee execution idempotency using PostgreSQL distributed locks. Expose a secure HTTP cron endpoint `/api/cron/scheduler` and provide an in-process background runner.

## 4. Detailed Implementation Specification

### 4.1 Distributed Idempotency Lock (`src/server/scheduler/lock-service.ts`)

  ```typescript
    jobName: string,

  ): Promise<boolean> {
    // INSERT INTO scheduler_locks (id, user_id, job_name, idempotency_key, status)
    // VALUES (...) ON CONFLICT DO NOTHING RETURNING id;
  }
  ```
- If lock already exists, the job was executed (or is actively executing) for this time window (e.g. `morning_prompt:user_id:2026-09-23`), returning `false`.

### 4.2 Periodic Sweepers (`src/server/scheduler/jobs/`)
1. **Overdue Tasks Sweeper (`overdue-tasks.ts`):**
   - Queries uncompleted tasks with `due_date < NOW()`.
   - Acquires lock `overdue_tasks:user_id:task_id:date`.
   - Emits `task.overdue` event to Event Bus.
   - Dispatches in-app notification: "Overdue Task: [Task Title]".
2. **Morning Plan & Evening Review Prompts (`planning-prompts.ts`):**
   - Evaluates user local time vs user preferences (default: 08:00 for morning, 21:00 for evening).
   - If morning window and daily plan not yet started:
     - Acquires lock `morning_plan:user_id:date`.
     - Emits `system.morning_routine_due`.
     - Creates notification with deep-link `/daily-plan`.
   - If evening window and evening review not yet completed:
     - Acquires lock `evening_review:user_id:date`.
     - Emits `system.evening_review_due`.
     - Creates notification with deep-link `/daily-plan`.
3. **Stagnant Goals Sweeper (`stagnant-goals.ts`):**
   - Identifies active goals whose `updated_at < NOW() - INTERVAL '14 days'`.
   - Emits `goal.stagnant` event.
   - Dispatches warning notification: "Goal Needs Attention: [Goal Title]".

### 4.3 Secure HTTP Cron Route (`src/app/api/cron/scheduler/route.ts`)
- Validates `Authorization: Bearer <CRON_SECRET>` using timing-safe comparison (`crypto.timingSafeEqual`).
- Iterates over all active users in the system and triggers `schedulerEngine.runSweepers(user.id)`.
- Returns execution summary (jobs executed, skipped, errors).

## 5. Security & Invariants

1. **Timing-Safe Auth:** `CRON_SECRET` validation avoids timing leak vulnerabilities.
2. **Strict Idempotency:** Jobs will never execute twice within their designated time window.
3. **Bounded Execution:** Sweeper loops have explicit batch sizes (`LIMIT 100`) to prevent database memory spikes.

## 8. Implementation Summary

**Completed:** 2026-09-28

### Delivered Modules:
- `src/server/scheduler/types.ts` — Zod schemas + TypeScript interfaces: `ScheduleConfig`, `SchedulerJobResult`, `SweepExecutionSummary`, `SchedulerOverallSummary`, `PeriodicSweeper`, `ScheduleEvaluationResult`, `scheduleConfigSchema`.
- `src/server/scheduler/cron.ts` — Zero-dependency cron parser using `Intl.DateTimeFormat` for timezone-safe date extraction. Supports 5-field cron matching, daily/interval/once schedule evaluation, 15-minute catch-up window for delayed ticks, and idempotency key generators.
- `src/server/scheduler/lock-service.ts` — PostgreSQL distributed locks via `scheduler_locks` table with atomic `INSERT ... ON CONFLICT DO NOTHING`, stale lock reclamation (15-minute default TTL), and `withJobLock` convenience wrapper.
- `src/server/scheduler/engine.ts` — Core `SchedulerEngine` class: registers 3 periodic sweepers, executes scheduled automations by delegating to `AutomationEngine.executeAutomationById()`, runs tenant-scoped sweeps with complete error isolation.
- `src/server/scheduler/worker.ts` — In-process background daemon with configurable interval, `unref()`-ed timer, duplicate instance protection, and graceful shutdown.
- `src/server/scheduler/jobs/overdue-tasks.ts` — Detects tasks with `dueDate < now` and non-terminal status, emits `task.overdue` event, creates warning notification, uses per-task-per-day idempotency locks.
- `src/server/scheduler/jobs/planning-prompts.ts` — Morning plan prompts (08:00–12:00 window) and evening review prompts (21:00+ window) with daily plan/evening review existence checks and per-action-per-day locks.
- `src/server/scheduler/jobs/stagnant-goals.ts` — Detects active goals with no updates in 14+ days, emits `goal.stagnant` event, creates warning notification, bounded to 100 goals per sweep.
- `src/app/api/cron/scheduler/route.ts` — Secure HTTP POST/GET endpoint with timing-safe `CRON_SECRET` Bearer token validation. Supports all-tenant and single-tenant execution modes.
- `scripts/worker.ts` — Standalone Docker worker entrypoint with SIGTERM/SIGINT graceful shutdown.

### Architecture:
- **Scheduler-Engine separation preserved:** Scheduler determines WHEN; AutomationEngine determines HOW.
- **No external dependencies added:** Pure TypeScript/PostgreSQL, no Redis, no cron libraries.
- **Tenant isolation guaranteed:** All queries and execution paths are scoped by `userId`.
